# Istruzioni per il frontend Pausa5

Questa cartella `PausaFiveFE/` contiene il frontend; `../PausaFiveBE/` contiene
il backend e il kit operativo condiviso.

Prima di lavorare leggere integralmente `../PausaFiveBE/AGENTS.md`,
`../PausaFiveBE/docs/12-DECISIONS.md` e il task assegnato con i suoi riferimenti
in `../PausaFiveBE/tasks/`. Applicare le istruzioni del kit anche qui.

La struttura approvata è ADR-015: i percorsi logici `frontend/` dei ticket
indicano questa cartella, quelli `backend/` indicano `../PausaFiveBE/`.
Non creare un frontend dentro la cartella backend. Un task alla volta;
aggiornare board e report nel kit condiviso.
